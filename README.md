# Fake News Detector 📰

An AI-powered Fake News Detection web app built using Python, Machine Learning, and Streamlit.

## Features
- Detects whether news is REAL or FAKE
- Simple and clean Streamlit UI
- Machine Learning based prediction
- Fast and lightweight

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit
